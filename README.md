# Дневной лимит

Считает, сколько можно тратить в день до ближайшей выплаты. Один HTML-файл, без сборки и зависимостей.

**Открыть:** https://deschenya.github.io/dzen-limit/

## Как считает

Выплаты приходят 10-го и 24-го числа. Если дата выпадает на субботу, воскресенье или государственный праздник Республики Беларусь, выплата сдвигается на предыдущий рабочий день.

Праздничные дни: 1–2 и 7 января, 8 марта, Радуница, 1 и 9 мая, 3 июля, 7 ноября, 25 декабря. Радуница подвижная — считается как девятый день после православной Пасхи.

Текущий день входит в период. Если выплата послезавтра, остаток делится на 2.

Переносы рабочих дней постановлениями Совета Министров не учитываются: они утверждаются отдельно на каждый год.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | всё приложение — разметка, стили, расчёт |
| `manifest.json` | запуск с домашнего экрана в полноэкранном режиме |
| `icon-180.png`, `icon-512.png` | иконки |

## Локально

Скачать `index.html` и открыть в браузере. Интернет нужен только при первом запуске — за шрифтами с Google Fonts; дальше они берутся из кэша, а без сети подставляются системные.
